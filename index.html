Gestion des astreintes

  • L’identifiant est au format nom.initiale du prénom (ex. ollivier.a), sans accent ni espace.
  • Pour une première connexion, votre mot de passe est : 1234. Vous choisirez ensuite le vôtre.
  • Mot de passe oublié ? Contactez votre administrateur pour réinitialiser votre mot de passe.
  • Pour une expérience optimale, ajoutez cette application à votre écran d’accueil :
    iPhone : Partager › Sur l’écran d’accueil
    Android : Menu ⋮ › Ajouter à l’écran d’accueil
